## Instrucciones de Ejecución

Este proyecto ha sido desarrollado utilizando React y Konva ('react-konva').

### Requisitos Previos
Tener instalado Node.js (versión 16 o superior recomendado).

### Instalación
1. Clona el repositorio o extrae el código en una carpeta.

2. Métete en la raiz del proyecto utilizando la terminal

3. Instala las dependencias necesarias ejecutando en tu terminal:

```bash
npm install
```

4. Levanta la aplicación

```bash
npm run dev
```
